Got Questions?

Frequently Asked Questions

Find answers to common questions about our platform concepts, asset tracking, and security design.

Is this a live trading platform? +

No, Davault Defi is currently a concept landing page and interactive frontend preview. Trading, live custody, deposits, and withdrawals are not enabled in this demo.

How does the portfolio overview work? +

The dashboard provides an illustrative overview of digital asset performance, market watches, and asset metrics to demonstrate clean UI organization for multi-asset portfolios.

Are my investments covered by insurance? +

Cryptocurrency holdings are not automatically covered by FDIC deposit insurance. Any actual protections, custody arrangements, or security controls must be verified against the live operator's terms.

How can I connect a backend or request more info? +

You can use the request demo form directly below this section or reach out to our team via $\text{support@devault.com}$ for integration and template inquiries.
